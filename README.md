# Personal Portfolio Site

A personal portfolio website built with HTML and CSS to 
showcase my academic background, contact information, and 
career goals as a Business Analytics and Information Systems 
student at the University of South Florida.

## Technologies Used

- HTML5
- CSS (custom properties, flexbox, responsive design)

## How to Run

1. Clone the repository:
   git clone https://github.com/mileytran04-cell/portfolio-site

2. Open index.html in any web browser.
   No installation or setup required.

## Features

- Responsive hero section with university branding
- Contact section with email, GitHub, and LinkedIn
- Education and GPA summary
- Career goals statement
- Clean footer with consistent styling

## What I Learned

This was one of the first projects where I built something 
completely from scratch without a template. I got more 
comfortable with CSS layout, especially using flexbox to 
center and position elements the way I actually wanted them. 
I also learned how to use CSS custom properties to keep 
colors and styles consistent across the page without 
repeating myself. On the GitHub side, this project helped 
me get used to the process of committing and pushing changes, 
which is something I know I will be using constantly going 
forward.
